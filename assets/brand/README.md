# ブランド素材の原本

ここに置くのは**原本だけ**。実行時にこのディレクトリを読むコードは無い。
配信用・掲載用は `tools/build-brand.sh` がここから生成する（→ `app/static/brand/`、`docs/images/brand/`）。

| ファイル | 中身 | 何から作ったか |
|---|---|---|
| `icon-master-1254.webp` | エンブレム単体（1254×1254・白地） | 支給された原画。すべての派生物の出どころ |
| `icon-master-transparent.png` | 同上の白地を抜いたもの | 上から生成。ロックアップの部品 |
| `brand-sheet.webp` | ブランドシート（2000×1529） | 支給。ワードマーク・タグライン・配色の版下 |
| `wordmark.png` | 「StreamForge」（678×99・透過） | ブランドシートの原寸ロゴタイプから切り出し |
| `tagline.png` | 「LIVE STREAMING TEST TOOL」（391×30・透過） | 同上 |

## 配色

`app/static/theme.css` には**入れていない**。画面の色を決めるのは theme.css のセマンティック
トークンだけ、という原則を崩さないため。ブランド色は README・ファビコン・ロックアップという
「theme.css の外側」でだけ使う。

| 名前 | 値 | 名前 | 値 |
|---|---|---|---|
| navy | `#0F172A` | brand-orange | `#FF4C00` |
| slate | `#1E293B` | amber | `#FFD200` |
| brand-blue | `#0070C0` | fur-brown | `#5C3A21` |
| cyan | `#00D2FF` | fur-tan | `#C69C6D` |

将来これらを画面のアクセントに採用するなら、`tools/check-contrast.py` と
`tools/palette-search.py` を通し、5シーンすべてで 4.5:1 / 3:1 を満たすことを確認してから。
現物の値をそのまま `--accent` に入れてはいけない。

## 採用しなかったもの

当初支給された SVG 一式（版下を自動トレースしたもの）は使っていない。ワードマークは輪郭が
波打ち、ファビコンは別物ににじんでいた。**ベクタであることより、原画に忠実であることを取った**。
アイコンがラスター原本である以上、ファビコンも SVG ではなく PNG で持つ。
